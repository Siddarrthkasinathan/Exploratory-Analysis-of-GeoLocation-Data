# 🏘️ Student Accommodation Recommendation using K-Means Clustering

This project uses **K-Means Clustering** to find the best accommodation options for students in any city, based on their preferences such as:

- 🏠 **Amenities**
- 💰 **Budget**
- 📍 **Proximity to location**

The system classifies accommodations into clusters to help **incoming students** choose the most suitable places to live.

---

## 📊 Project Stages

1. **Data Collection**
2. **Data Preprocessing**
3. **Feature Engineering**
4. **Clustering with K-Means**
5. **Visualization**
6. **Result Analysis**
